# 覚醒 — 改良プロジェクト 共通ルール

ブラウザ単体で動く1対1コマンドバトル。目標は **「ネイティブのスマホゲームアプリと見分けがつかない品質」**。
出力は依存ゼロの HTML 1ファイル (`dist/awakening.html`)。ソースは編集競合を避けるため分割してある。

## ビルドと確認（必ず自分の変更のあとに実行する）

```
cd games/awakening
node build.mjs                      # src/ -> dist/awakening.html
node tools/smoke.mjs                # 起動エラー・横スクロール・タップ領域を検査（exit 1 で失敗）
node tools/smoke.mjs --screen battle --shot /tmp/x.png --viewport   # 画面を指定して撮影
node tools/smoke.mjs --script tools/flows/<name>.mjs                # 操作フローを流す
```
撮影した PNG は Read ツールで**必ず自分の目で見る**。見ずに「できた」と言わない。

## 絶対に守ること

1. **担当ファイル以外を書き換えない。** 他の担当の領域に手を入れたくなったら、報告に「依頼」として書く。
2. `dist/awakening.html` を直接編集しない。必ず `src/` を直して `node build.mjs`。
3. **外部依存を増やさない。** CDN・npm・画像ファイル禁止。フォントは現状の Google Fonts 参照のみ許可し、
   オフラインでも崩れないようフォールバックを効かせる。
4. 既存のセーブデータ（`localStorage` の `awakening_trpg_battle_v1`）を壊さない。形式を変えるなら移行処理を書く。
5. ゲームエンジン（`09-engine.js`）は UI を知らない、UI は戦闘計算をしない、という分離を維持する。
6. コメントは日本語、既存コードの書き方・命名・密度に合わせる。

## 「スマホアプリ品質」の判定軸（批評家はここを見る）

- **触り心地**: 44px 以上のタップ領域 / 押下フィードバック（スケール・リップル・触覚 `navigator.vibrate`）/
  60fps（`transform` と `opacity` だけでアニメーションする。`width`/`top` のアニメは原則禁止）/ 慣性スクロール。
- **画面遷移**: 無言で切り替わらない。方向のある遷移、戻る操作（ハード戻る `popstate` 対応）。
- **情報設計**: 1画面1目的。親指の届く下部に主要操作。読み込み・空・エラーの状態が全部デザインされている。
- **画面サイズ耐性**: 360x640 の小型端末から iPad まで破綻しない。ノッチ・ホームインジケータ（safe-area）対応。
- **手応え**: 演出に意味がある（ダメージの重さが見た目に出る）。待ち時間にスキップ手段がある。
- **アクセシビリティ**: コントラスト比 4.5:1 以上、`prefers-reduced-motion` 尊重、フォーカス可視、スクリーンリーダー用ラベル。
