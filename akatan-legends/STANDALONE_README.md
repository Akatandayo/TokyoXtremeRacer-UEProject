# あかたんLegends — オフライン単体版(テストプレイ用)

## 遊び方

`akatan-legends.html` を**ブラウザにドラッグ&ドロップ**するか、ダブルクリックで開くだけです。
サーバのインストールも `npm install` も不要です。推奨は Chrome / Edge / Firefox の最新版。

- 進行状況（所持キャラ・レベル・編成・クリア状況）は**そのブラウザの localStorage に保存**されます。
  同じブラウザで開き直せば続きから遊べます。別のPCやシークレットウィンドウには引き継がれません。
- 進行をリセットしたい場合は、ブラウザのサイトデータ削除、またはデベロッパーツールのコンソールで
  `localStorage.removeItem('akatan.standalone.save.v1')` を実行してリロードしてください。

## 遊ぶ流れ

```
HOME → キャラ(所持探索者を確認) → 編成(5人パーティを組む)
     → ダンジョン(ステージ選択) → 戦闘開始 → 完全オート戦闘を観戦
     → 勝利 → EXP/ゴールド獲得 → レベルアップ
```

戦闘中は操作しません。**倍速(1x/2x/4x)・一時停止・スキップ**が使えます。
勝敗は「誰を編成したか」「どの装備を持たせたか(Phase2以降)」「どのAI戦術を選んだか」で決まります。

## 見てほしいところ

- **SUMMON(ガチャ)** — 排出率は全件公開しています。天井60連、10連はSR以上を1枠保証。
  重複キャラは素材に変換されるので完全なハズレにはなりません
- **装備** — 同じ名前でも性能が違います(ベース + Prefix + Suffix + ランダム値幅 + 特殊効果)。
  装着前に「現在値 ▶ 装着後値 (+n/-n)」で比較できます
- **孤月 紅葉(幽波紋)** — ガチャから出ます。ピックアップバナーもあります。
  「集団戦では最強、ボスには脆い」ガラスキャノンとして調整してあります
- **編成画面の「発動コンボ」** — 特定のキャラを組み合わせると発動します。「あと1人で成立」も表示されます。
  孤月紅葉のコンボ相手「電子 独(幽波紋)」は実装予定のため、現状は成立しません
- **キャラ詳細のAI戦術** — 戦術を変えると戦闘中の行動が変わります
- **戦闘演出** — 会心 / 属性有利 / 必殺技 / 覚醒 / コンボ / 撃破 でそれぞれ演出が違います
- **ステージの難易度** — ボスは正面から殴るだけでは勝てないよう調整しています。
  ステージは順番にクリアしないと開放されません

## この単体版と本体の違い

| | オフライン単体版(このファイル) | 本体(通常構成) |
|---|---|---|
| 構成 | ブラウザ内で完結 | ブラウザ + Node/Express + SQLite |
| 戦闘・育成計算 | **本体と同じモジュールを使用** | サーバ側で処理 |
| データ | `data/` の本物のマスターデータを埋め込み | サーバが `data/` から読み込み |
| セーブ | localStorage | SQLite |
| 用途 | テストプレイ・配布 | 開発・将来のオンライン要素 |

戦闘計算(`server/src/battle`)と育成計算(`server/src/services/progression.ts`)は、
単体版と本体で**同じソースを共有**しています。単体版のために計算を書き直すと
「単体版では勝てるのに本体では負ける」事故になるためです。

なお、ガチャ・PvP・レイドなど**不正が問題になる要素はサーバ権威が必須**なので、
それらは本体構成側にのみ実装します(設計書§37)。この単体版はあくまでテストプレイ用です。

## 本体をローカルで動かす場合

```bash
cd akatan-legends
npm install
npm run dev          # サーバ(8787) + クライアント(5173) を同時起動
# → http://localhost:5173 を開く
```

## 不具合を見つけたら

「どの画面で」「何をしたら」「何が起きたか」を教えてください。
戦闘に関するものは、可能ならブラウザのコンソール(F12)のエラーも添えてもらえると助かります。
